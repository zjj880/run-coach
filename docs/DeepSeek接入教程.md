# DeepSeek 接入教程（交我跑 · 手机 / 电脑通用）

> 目标：10 分钟把 DeepSeek 的 API 填进「交我跑」，让 AI 教练、训练评估、课表识别可以在手机上直接用。
> 全程只需要三样东西：**接口地址**、**模型名**、**API 密钥**。

---

## 零、更快的做法：App 里点一下就好

新版本（0.6.0 起）在「我的 → AI 接口」里内置了服务商快捷填充：

1. 打开 **我的 → AI 接口**
2. 服务商点 **DeepSeek** —— 接口地址和模型自动填好，不用手打
3. 点 **「打开 DeepSeek 密钥页」**（会自动跳到平台密钥页）
4. 在网页里创建密钥 → 复制
5. 回到 App 点 **「粘贴密钥」**（自动从剪贴板读取）
6. 点 **「测试并保存」**，看到「已连接 · deepseek-chat」即完成

下面的手动流程作为备选：如果自动填的不符合你的账号情况，可以照着改。

---

## 一、先搞清楚要填什么

| 项目 | DeepSeek 的值 |
|---|---|
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-chat`（日常首选，速度快、便宜）<br>`deepseek-reasoner`（推理更强，慢一些、贵一些） |
| API 密钥 | `sk-` 开头的一长串，在 DeepSeek 开放平台创建 |

> 说明：DeepSeek 兼容 OpenAI 的 Chat Completions 协议，所以「交我跑」里只填这三个就能用。
> 如果平台文档里给出了更新的模型名（如 `deepseek-v4-flash` / `deepseek-v4-pro`），直接把模型那一栏换成文档里的名字即可；`deepseek-chat` / `deepseek-reasoner` 是长期保留的别名。

---

## 二、在 DeepSeek 平台拿密钥

### 1. 登录开放平台

浏览器打开：<https://platform.deepseek.com/>

手机号验证码或微信扫码登录。

### 2. 完成实名认证

首次使用需要在「个人信息」里完成实名认证，否则无法创建密钥、无法调用。

### 3. 确认余额

在「用量信息 / 充值」页查看余额。新账号可能有赠送额度，用完后按 token 计费。
余额为 0 时接口会返回 `402 Insufficient Balance`，表现就是 App 里「测试并保存」失败。

充值入口：<https://platform.deepseek.com/top_up>

### 4. 创建 API 密钥

1. 左侧菜单进入 **API keys**
2. 点「创建 API key」
3. 起个名字，例如 `jiaowopao-phone`（名字只是方便你自己认）
4. 创建后**立刻复制** `sk-` 开头的完整密钥

> ⚠️ 密钥**只显示一次**，关掉弹窗就看不到了。丢了只能删除重建。
> 不要发到群里、不要写进笔记、不要提交到代码仓库。

## 三、填进「交我跑」

### 手机 App（也可用上面的快捷方式）

1. 打开「交我跑」→ 底部 **我的**
2. 点 **AI 接口**（在「佳明中国区」下面）
3. 服务商选 **DeepSeek**（自动填地址与模型），或按下表手动填写：

| 输入框 | 填什么 |
|---|---|
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-chat` |
| API 密钥 | 粘贴刚才复制的 `sk-...` |

4. 点 **「测试并保存」**
5. 显示「已连接 · deepseek-chat」就成功了

> 密钥保存在手机系统安全存储里，只在本机使用，不会上传。

### Windows / Linux 桌面版

同样在「我的 → AI 接口」填写。电脑版会把配置加密保存在本机，不需要启动任何服务。

### 浏览器预览（开发用）

浏览器预览的 AI 需要先在电脑上运行本机服务：

```bash
npm run ai
```

然后浏览器里同样填上面三项。

## 四、验证是否真的能用

按顺序试三个功能，从易到难：

1. **心情回应**：「今天」→ 补充晨间打卡 → 填写心情 → 生成心情回应（最轻量，只发几个字）
2. **训练评估**：「课表」→ 选一天有活动的日期 → 训练评估 → 用 AI 评估
3. **AI 教练对话**：「今天」→ 和 AI 教练聊聊 → 发送一句话

任意一个能返回正常中文内容，说明接入成功。

## 五、常见报错对照表

| App 里的提示 | 原因 | 处理 |
|---|---|---|
| `HTTP 401` / `HTTP 403` | 密钥错误、被删除、或模型无权限 | 回平台重新创建密钥；确认没有多复制空格 |
| `HTTP 402` 或提示余额 | 账户余额不足 | 充值后再试 |
| `HTTP 404` | 接口地址或模型名写错 | 地址用 `https://api.deepseek.com/v1`；模型用 `deepseek-chat` |
| `HTTP 429` | 请求太频繁 / 额度限制 | 等一会儿再试 |
| `HTTP 400` | 提交内容不被支持（例如图片、超长文本） | 换纯文字识别；DeepSeek 文本模型不保证看图能力 |
| `接口地址须使用 HTTPS` | 填了 `http://` | 改成 `https://api.deepseek.com/v1` |
| `无法连接 AI 服务` | 网络问题（校园网/代理/VPN） | 换网络，或关掉代理再试 |
| `AI 模型响应超时` | 内容太长或模型排队 | 缩减文字量，或改用 `deepseek-chat` |
| `模型没有返回可读取的文本` | 模型返回格式异常 | 重试；仍失败可换 `deepseek-reasoner` 试 |

## 六、费用与模型选择建议

| 场景 | 建议模型 | 说明 |
|---|---|---|
| 课表识别、心情回应、日常教练对话 | `deepseek-chat` | 快、便宜，够用 |
| 训练评估复盘（要推理） | `deepseek-reasoner` | 质量更好，慢一些、贵一些 |
| 图片课表识别 | 建议用支持视觉的模型（DeepSeek 文本模型不保证） | 图片识别可选其他服务商 |

> 具体价格以平台「模型 & 定价」页为准。一次课表识别或训练评估通常只有几千 token，日常使用成本很低。

---

## 七、安全性建议

1. 密钥只填在 App 的「API 密钥」输入框，**不要**拼进地址（如 `?key=` 或 `user:pass@`），App 会拒绝
2. 一个人一个密钥，方便随时单独删除
3. 怀疑泄漏：回平台删除该密钥并重新创建，然后在 App 里重填
4. 手机丢了：改密码 + 删除密钥；App 里的密钥在系统安全存储中，卸载即清除

---

## 八、换个服务商也一样（可选）

「交我跑」只要求「兼容 Chat Completions 的 HTTPS 接口」，所以换成别家只需改两个值：

| 服务商 | 接口地址示例 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` 等 |
| OpenRouter | `https://openrouter.ai/api/v1` | `deepseek/deepseek-chat` 等 |
| 自建网关 | `https://你的域名/v1` | 网关里配置的模型名 |

> 注意：只能填 `https://`；`http://` 的地址会被拒绝（防止密钥在明文网络里被窃取）。

## 九、附：命令行自测（进阶）

想先确认密钥本身可用，可以在电脑终端跑：

```bash
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的密钥" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"你好"}]}'
```

返回 JSON 里 `choices[0].message.content` 有内容，说明密钥没问题；此时 App 里一定也能用。
