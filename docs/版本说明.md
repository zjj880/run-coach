# 版本说明

版本号单一来源：`app.json` 的 `expo.version`（Android 另有 `expo.android.versionCode`）。
`package.json` 的 `version` 必须与之一致，CI 用 `npm run version:check` 校验。

## 规则

- 版本号 `MAJOR.MINOR.PATCH`：功能新增升 MINOR（0.7.0 → 0.8.0），修复升 PATCH（0.7.0 → 0.7.1）
- `versionCode` 只增不减，每次发版 +1
- 每次发版打 tag `vX.Y.Z`，tag 指向的提交里 `app.json` 版本必须等于 tag
- 新版本要登记到 `scripts/version-check.mjs` 的 history 数组

## 曾经的问题（已修复）

- 桌面 exe 的「属性 → 详细信息」显示的是 Electron 的版本（45.4.1）和产品名 Electron，
  容易被当成 App 版本。0.7.1 起用 rcedit 写入 `FileVersion/ProductVersion/ProductName/FileDescription`
  与品牌图标，属性里会正确显示「交我跑 0.7.1」。
- 根 `package.json` 曾长期是 `1.0.0`，与 `app.json` 的版本不一致；0.7.1 起同步并加 CI 校验。
- 0.4.x 期间同一版本号存在多个构建（Ink/FinalTheme/Campus 等），现已统一为一个发布包。
