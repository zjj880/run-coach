# 佳明训练记录导入指南

> 适用版本：v0.4.1 及以上 ｜ Windows / Linux 桌面版、Android（arm64）内测版

佳明数据的导入分三种场景，按需要选：

| 场景 | 入口 | 用途 |
|---|---|---|
| A. 日常同步 | 我的 → 连接佳明 | 当天睡眠/HRV/静息心率 + 最近 14 天活动 |
| B. 历史批量 | 我的 → 同步历史活动 | 把过去几周/几个月的活动一次拉回来 |
| C. 单次明细 | 课表 → 训练评估 → 同步佳明明细与 FIT | 某次活动的圈数据、心率曲线、FIT 文件 |

---

## 零、先准备：中国区个人 API 密钥

> 只支持**中国区** Garmin Connect 账号（`connect.garmin.cn`）。国际区账号（garmin.com）不适用。

### 电脑上获取

1. 浏览器打开：<https://connect.garmin.cn/app/settings/personalApiToken>
2. 用你**手表的佳明中国区账号**登录（手机号或邮箱，和 Garmin Connect App 同一个账号）
3. 进入「个人 API 密钥」页面，点击创建/生成
4. 页面会显示一串 `GCDC_` 开头的密钥 —— **只显示一次**，请立刻复制并妥善保存
5. 回到 App：「我的 → 连接佳明」粘贴密钥 → 点「连接并同步」

### 手机上获取

1. 打开 App：「我的 → 连接佳明」→ 点 **「打开佳明密钥页」**（会跳到系统浏览器）
2. 在浏览器里登录佳明中国区账号 → 生成密钥 → 复制
3. 返回 App，点 **「粘贴密钥」**（自动读取剪贴板；也可长按输入框手动粘贴）
4. 点「连接并同步」

> 手机上复制不方便时，点「复制密钥页链接」，把链接发到电脑打开生成，再把密钥发回手机粘贴。

> 小技巧：手机上不方便复制时，可以把密钥页链接发到电脑，在电脑上生成后复制，再发回手机粘贴。

### 密钥注意事项

- 密钥形如 `GCDC_xxxxxxxx...`，只显示一次，丢了只能**重新生成**（旧密钥会失效）
- 密钥只保存在本机：手机存系统安全存储，Windows 版由系统加密保存
- 不要发给别人、不要提交到代码仓库

## 一、日常同步（推荐每次训练后做一次）

1. 训练结束，先在 **Garmin Connect App** 里确认活动已上传（手表 → 手机同步完成）
2. 打开跑步教练 →「我的 → 佳明中国区」→ 点 **「立即同步」**
3. 也可在「课表」顶部点 **「立即同步佳明」**，或从「今天」页点同步

同步完会做三件事：
- 更新当天睡眠、夜间 HRV、静息心率（缺失的指标显示「未同步」，不会编造）
- 拉取最近 **14 天**的活动，写入「实际执行」
- **自动归类**：按心率、配速、先后顺序把活动分成主课 / 次课 / 热身 / 冷身

重复同步不会产生重复活动（按佳明活动 ID 合并），你手动改过的归属会保留。

---

## 二、历史批量导入（补以前几周的数据）

1. 「我的 → **同步历史活动**」
2. 填写日期范围：
   - 开始日期：例如半年前的某天
   - 结束日期：默认今天
   - 规则：一次最多 **366 天**，约 **2000 条**活动，超过会提示分段同步
3. 点「开始同步」，活动多时需要等 1–2 分钟（每页 100 条自动翻页）
4. 完成后提示「已导入 N 条历史活动」
5. 去「**记录**」页查看：按月份倒序排列，显示公里、时长、配速、平均心率

补充说明：
- 历史活动先只有摘要（距离/时长/心率），**不含圈数据**；需要时再对单次活动同步明细
- 导入后训练周期会自动扩展，课表能翻到更早的周
- 想同步更早的记录，改日期段再跑一次即可，已存在的不会重复

## 三、单次活动的明细与 FIT

1. 「课表」→ 找到那天 → 第三列「训练评估」
2. 点「**同步佳明明细与 FIT**」（每次最多 12 条活动）
3. 同步后可看到：
   - 佳明详情：最高心率、步频、步幅、爬升、功率、移动时长、训练效果、分段汇总
   - FIT：逐圈配速柱状图、心率曲线（可点选查看采样）
4. 再点「用 AI 评估」生成复盘

FIT 下载失败不影响评估：页面会显示失败原因，明细和天气仍可用。

## 四、电脑和手机的差异

| 项目 | 手机原生 App | Windows / Linux 桌面版 | 浏览器预览 |
|---|---|---|---|
| 访问佳明 | 手机直接访问 | 内置本机服务代理 | 需先启动本机服务 |
| 密钥保存 | 系统安全存储 | 系统加密保存 | 仅服务内存（重启需重填） |
| 打开密钥页 | 跳系统浏览器 | 调系统默认浏览器 | 新标签页 |
| 历史同步 | 支持 | 支持 | 支持（需本机服务） |
| AI 功能 | 需自建后端 | 内置本机服务 | 需本机服务 |

> 浏览器预览要 AI/佳明代理时，在项目目录运行 `npm run ai`（仅监听 127.0.0.1:8091）。

## 五、常见错误与处理

| 提示 / 现象 | 原因 | 处理 |
|---|---|---|
| 请输入 Garmin Connect 中国区创建的个人 API 密钥 | 粘贴的不是 `GCDC_` 开头 | 重新复制完整密钥 |
| 佳明暂时无法读取活动明细和 FIT | 佳明接口临时不可用 | 稍后重试；只评估摘要也可以 |
| 佳明 FIT 下载返回重定向 | 佳明 CDN 跳转异常 | 重试；跨域跳转会被安全拦截 |
| 同步成功但没有新活动 | 手表还没上传 / 不是中国区账号 / 活动在 14 天前 | 先在 Garmin Connect 确认活动存在；更早的用「同步历史活动」 |
| 睡眠/HRV 显示未同步 | 当天数据还没生成 | 白天同步常有缺失，睡前或次日再同步 |
| 连接后立即报错 | 密钥已失效或被重新生成 | 去密钥页重新生成再填 |
| 提示区服不符 | 用了国际区账号 | 需要中国区账号（connect.garmin.cn） |

## 六、推荐的使用节奏

- **每天**：训练后同步一次（或打开 App 自动同步）→ 看「今天」建议
- **每周**：课表回顾计划 vs 实际 → 对关键课做一次 AI 评估
- **每阶段开始/结束**：同步历史补齐 → 在「记录 → 训练周期」划阶段，看阶段里程与天数
- **换设备前**：复制数据目录备份（见《使用指南》第二节）
