# 跑步教练 · 使用指南

> 版本：v0.4.1 ｜ 适用：Windows / Linux 桌面版、Android（arm64）内测版
> 所有训练数据只保存在你自己的设备上。

---

## 一、这是什么

一个本地优先的跑步训练助手，帮你回答三件事：**今天怎么练、怎么休、怎么吃**。

- **计划**：动态课表（本周/下周、计划 vs 实际 vs 评估）
- **执行**：佳明中国区同步、手动补记、历史批量导入
- **反馈**：晨间打卡、训练评估、AI 教练追问
- **积累**：训练笔记（力量/跑技/恢复/比赛/学习）、训练阶段统计

数据全部本机保存，没有账号、没有云端。

---

## 二、安装与启动

### Windows x64

1. 下载 `RunCoach-Windows-x.y.z-x64.zip`
2. **完整解压**到一个文件夹（不要只双击压缩包里的 exe）
3. 双击 `RunCoach.exe`

### Linux x64

```bash
tar -xzf RunCoach-Linux-x.y.z-x64.tar.gz
cd RunCoach-Linux-x.y.z
chmod +x RunCoach chrome-sandbox
./RunCoach
```

### Android（arm64 内测）

1. 安装 `run-coach-android-x.y.z.apk`，允许「未知来源」
2. 仅支持 arm64 设备；本地调试签名，不能上应用商店

### 数据位置

| 平台 | 位置 |
|---|---|
| Windows | `%APPDATA%\RunCoach` |
| Linux | `~/.config/RunCoach` |
| Android | App 私有目录（随应用） |

> 想备份或迁移，复制整个目录即可；想重开一份干净数据，把目录改名再启动。

## 三、5 分钟上手

1. **我的 → 连接佳明**：填入中国区个人 API 密钥，点「连接并同步」
2. **我的 → 同步历史活动**：选起始日期（如半年前）到结束日期，一次拉回历史
3. **记录 → 训练周期**：按阶段划分（基础期 9/1–10/5、专项期 10/6–11/15…）
4. **今天**：点选起床感受，看今日建议；需要时和 AI 教练聊出方案

## 四、页面说明

### 1. 今天

| 区块 | 作用 |
|---|---|
| 今早起床感受 | 一点即存（良好/一般/偏累），建议立刻重算 |
| 补充晨间打卡 | 不适、可训练时间、工作安排、心情、备注；可生成 AI 心情回应 |
| 今日建议（深色卡） | 今天练什么 + 为什么；已确认的 AI 方案会替换显示 |
| 今日可训练时段 | 来自「日程与训练时间」，点进去选中空档会让建议按时长调整 |
| 晨间数据 | 睡眠 / 夜间 HRV / 静息心率；「查看依据」说明数据来源与缺失项 |
| 休息 / 饮食 | 建议的一部分，随训练强度与身体状态变化 |
| N 条活动待归类 | 出现说明有同步来的活动还没定主课/次课，点「自动归类」或去课表手动改 |

**建议的优先级**（了解规则就不容易困惑）：
身体危险信号 > 发热/症状加重 > 其他不适 > 已训练记录 > 休息日 > 恢复指标偏离 > 正常安排。

### 2. 课表

三列结构：**计划 ｜ 实际执行 ｜ 训练评估**。

**顶部**
- 设置周期：训练周期起始日与周数
- 识别导入：粘贴文字/图片，让 AI 识别成课表（需先配置 AI 接口）
- 立即同步佳明：拉今天指标 + 最近 14 天活动

**每一天可做**
- 日程：查看/设置当天空档与训练时间
- ＋ 添加训练 / 调整：新增或修改当日课（调整需选动作与原因：缩短/降强度/换课/取消/改期）
- ＋ 补记活动：手动记录一次训练
- 自动归类：把手表活动按心率/配速自动分主课/次课/热身/冷身
- 标记跳过：没练但不想显示为缺失
- 评估训练 / 查看评估 / 查看数据：进入当日评估

**评估弹窗**
- 上方：计划 vs 实际、活动明细（配速、心率、Garmin 明细、FIT 逐圈配速图与心率曲线）
- 「填写体感」：RPE、心率来源、读数是否存疑、天气偏冷、备注
- 「用 AI 评估」：生成五段式复盘（摘要/执行/配速心率/下次建议/数据局限）
- 「继续问教练」：针对这次评估追问，如「心率偏高说明什么？」

> 课表或活动变了，评估会显示「待重新评估」，需要重新点评估。

### 3. 记录

顶部切换 **活动 / 训练笔记**。

**活动**
- 按月份倒序列出全部活动（含同步历史、手动补记、导入）
- 显示公里、时长、配速、平均心率、归属
- 按训练周期筛选；点开可「改归属」或「查看评估」

**训练笔记**
- 记录力量、跑技、恢复、比赛、学习
- 点「＋ 添加笔记」写：做了什么、组次、感受、学到什么
- 从 Excel 导入时，会自动生成这些笔记

**右上两个按钮**
- 导入记录：导入 Excel(.xlsx) / CSV
- 训练周期：划分训练阶段

### 4. 我的

| 区块 | 作用 |
|---|---|
| 佳明中国区 | 连接/管理密钥、立即同步、**同步历史活动** |
| 导入训练记录 | 与记录页入口相同（后续版本会合并） |
| AI 接口 | 配置兼容 Chat Completions 的地址/模型/密钥，测试并保存 |
| 环境温湿度估计 | 开关：开启时同步明细会用取整到约 1 公里的起点查询 Open-Meteo |
| 佳明同步演示 | 没连佳明时用假数据体验流程；可切换「模拟数据缺失」 |

## 五、佳明接入

### 获取密钥

1. 打开 [中国区 Garmin Connect 个人 API 页面](https://connect.garmin.cn/app/settings/personalApiToken)
2. 创建令牌，复制 `GCDC_` 开头的密钥
3. App「我的 → 连接佳明」粘贴，点「连接并同步」

> 只支持**中国区**账号（`personal.connectapi.garmin.cn`）。国际区账号请用国际版工具。

### 同步什么

| 数据 | 范围 |
|---|---|
| 睡眠、夜间 HRV、静息心率 | 同步当天 |
| 睡眠基线参考 | 前 28 天 |
| 活动列表 | 最近 14 天（自动同步） |
| **历史活动** | 「同步历史活动」按日期范围拉取，一次最多 366 天，自动翻页（100 条/页） |
| 活动明细 / FIT | 评估弹窗里「同步佳明明细与 FIT」，每次最多 12 条 |

- 重复同步**不会产生重复活动**（按佳明活动 ID 合并），你确认过的归属会保留。
- FIT 明细按需拉取，所以历史活动先只有摘要，需要圈数据时再单独同步。

### 常见错误

| 提示 | 处理 |
|---|---|
| 未接受该密钥 | 检查是否中国区账号、密钥是否过期 |
| 无法连接佳明中国区 | 检查网络；国际网络环境可能需要代理 |
| 佳明暂时无法读取活动明细和 FIT | 稍后重试，或只用摘要数据评估 |

## 六、AI 接入

支持任何兼容 **Chat Completions** 的服务（OpenAI 兼容网关、DeepSeek、OpenCode、自建服务等）。

1. 「我的 → 设置 AI 接口」
2. 点服务商（**DeepSeek / OpenAI / OpenRouter**）——接口地址与推荐模型自动填好，只需再粘密钥
3. 点「打开 X 密钥页」→ 在网页创建并复制密钥 → 回 App 点「粘贴密钥」
4. 点「测试并保存」——测试通过才会保存

> 自定义服务商：选「自定义」后手动填地址与模型；地址必须以 `https://` 开头。

**能做什么**

| 能力 | 输入 | 说明 |
|---|---|---|
| 课表识别导入 | 你粘贴的文字或选的图片/TXT/CSV | 识别成课表条目，逐条确认后导入 |
| 训练评估 | 所选日期的课表 + 活动摘要 + 体感 | 生成五段式复盘 |
| 评估追问 | 已保存的评估 + 同一份数据 + 对话 | 最多 12 轮 |
| 心情回应 | 只发心情与备注两项 | 生成 2–4 句回应 |
| 教练对话 | 课表/打卡/恢复指标/近期训练 + 对话 | 可追问，最后确认今日方案 |

**注意**
- 密钥只存在于本机：手机存系统安全存储、Windows 由系统加密、浏览器预览存本机服务内存；不会上传。
- 手机端 App 可直接调用你配置的模型接口（不再需要电脑）；浏览器预览仍需先在电脑上运行 npm run ai。
- 图片识别需要模型支持视觉输入。

## 七、导入已有训练记录（Excel / CSV）

1. 「记录 → 导入记录」→ 选文件
2. 预览确认（活动条数、计划条数、笔记条数、日期范围、总里程）
3. 点导入

**Excel 识别规则**（适合本项目的课表模板）

- 自动挑选含「日期 / 实际」列的「训练计划」类工作表
- 识别的列：日期、计划公里、跑步主课、历史计时、实际跑步公里、历史分段
- 额外读到：基本信息表（比赛日与目标）→「比赛」笔记；恢复与比赛表 → 营养/流程笔记；力量与跑技动作表 → 动作库笔记

**CSV 表头**（列顺序不限）

```
日期,公里,分钟,平均心率,标题,训练内容
2026-09-01,10.5,54,144,轻松跑,"分段1; 分段2"
```

**去重规则**：同一天、里程差 ≤0.1 km、时长差 ≤1 分钟视为同一条，保留已有数据（佳明优先）。

## 八、训练周期与训练阶段

两个概念，别混：

| 概念 | 在哪 | 作用 |
|---|---|---|
| **训练周期**（周数） | 课表 → 设置周期 | 课表显示几周、从哪天开始 |
| **训练阶段**（periods） | 记录 → 训练周期 | 基础期/专项期/调整期/比赛期，用于按阶段统计 |

建议做法：
1. 先用「设置周期」把课表范围对齐你的训练计划
2. 再用「训练周期」把时间划成 2–5 个阶段
3. 记录页顶部即可按阶段筛选，看每个阶段的训练天数与里程

> 导入历史活动后，周期会自动扩展覆盖导入的日期范围。

## 九、常见问题

**同步了历史活动，为什么课表里看不到？**
历史活动在「记录」页；课表只显示当前周期内的日期。导入后周期会自动扩展，如果仍看不到，去「课表 → 设置周期」把起始日期往前调。

**评估按钮为什么是灰的？**
当天没有活动记录。先同步或补记活动。

**为什么活动显示「待归类」？**
还没确定主课/次课/热身/冷身。点「自动归类」，或逐条点开改归属。

**换了电脑/手机，数据怎么办？**
复制数据目录（见第二节）到新设备对应位置即可。

**AI 报 400 / 401？**
- 400：协议不匹配或缺少服务商要求的请求头；确认地址是 Chat Completions 兼容接口
- 401/403：密钥或模型权限问题
- 429：额度限制

**数据会丢吗？**
保存在本机；清理应用数据、卸载应用会丢。重要数据建议定期复制数据目录。

## 十、隐私

| 数据 | 会不会出网 |
|---|---|
| 训练记录、课表、打卡、笔记 | ❌ 只在本机 |
| 佳明密钥 | 只在本机（加密存储），仅用于向佳明请求数据 |
| AI 请求 | ✅ 只发完成当前任务所需字段（见上文各能力说明） |
| 环境温湿度 | ✅ 可选；开启时发送取整到约 1 公里的起点与整点时间到 Open-Meteo，可随时关闭 |
| 原始 FIT / GPS / 完整心率采样 | ❌ 不会发给 AI |
